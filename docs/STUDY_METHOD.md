# How to Study Mathematics for ML

## The four-pass method
1. **Intuition:** watch a visual explanation or read an introduction; ask what the concept describes.
2. **Derivation:** write the definition and derive important equations. Track assumptions and dimensions.
3. **Practice:** solve problems without immediately checking solutions. Redo missed problems later.
4. **Implementation:** build a small Python/NumPy example and compare it with a trusted library or hand calculation.

## Daily template (2 hours)
| Time | Activity |
|---|---|
| 40 minutes | Lecture or textbook |
| 40 minutes | Paper-and-pencil problems |
| 30 minutes | Python implementation |
| 10 minutes | Recall and review |

For a 1-hour day, use 20 minutes learning, 25 minutes problem-solving, and 15 minutes coding/review.

## When to move on
- State the concept in your own words.
- Write the key formula and explain its symbols.
- Solve a basic problem without notes.
- Explain one ML use case.
- Implement a simple example and sanity-check the output.

Do not wait for perfect mastery. Keep unresolved questions and revisit them when a project makes them relevant.

## Mistake log
For each mistake, write: (1) what you attempted, (2) what went wrong, (3) the correct reasoning, and (4) a similar problem to retry later.
