# Resource Library

Choose one primary resource per subject; use supplements when a concept is unclear. The links below provide free learning material, although some platforms may offer optional paid services.

## Prerequisites
- [Khan Academy Mathematics](https://www.khanacademy.org/math) — algebra, functions, logarithms, trigonometry.
- [NumPy Quickstart](https://numpy.org/doc/stable/user/quickstart.html) — arrays, shapes, vectorized operations.

## Linear Algebra
- [3Blue1Brown](https://www.3blue1brown.com/topics/linear-algebra) — visual intuition.
- [MIT 18.06](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) — lectures and problem sets.
- [MIT 18.065](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/) — matrix methods in data analysis and ML.
- [Mathematics for Machine Learning](https://mml-book.github.io/) — free textbook and exercises.
Suggested order: visual series → selected MIT lectures/problems → textbook review.

## Calculus
- [3Blue1Brown Calculus](https://www.3blue1brown.com/topics/calculus) — intuition for derivatives, chain rule and integrals.
- [MIT 18.01](https://ocw.mit.edu/courses/18-01-single-variable-calculus-fall-2006/) — single-variable calculus.
- [MIT 18.02SC](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/) — partial derivatives and gradients.
- [MML book](https://mml-book.github.io/) — ML-focused vector calculus.
Priority: differentiation, chain rule, partial derivatives and gradients.

## Probability and Statistics
- [Seeing Theory](https://seeing-theory.brown.edu/) — interactive intuition.
- [Harvard Statistics 110](https://stat110.hsites.harvard.edu/) — probability, random variables, expectation and distributions.
- [MIT 18.05](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/) — inference, distributions and estimation.
- [MML book](https://mml-book.github.io/) — ML-oriented reference.
Suggested order: Seeing Theory, then choose Harvard Stat 110 or MIT 18.05 as the main course.

## Optimization
- [Stanford CS229](https://cs229.stanford.edu/) — mathematical ideas behind ML algorithms.
- [MML book](https://mml-book.github.io/) — structured reference.
- [Dive into Deep Learning](https://d2l.ai/) — theory alongside code.
Learn gradients first, then implement gradient descent before studying advanced optimizers.

## Discrete Mathematics
- [MIT 6.042J](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/) — logic, proofs, counting, graphs and recurrences.
- [MIT Open Learning Library](https://openlearninglibrary.mit.edu/) — interactive practice where available.
This supports algorithmic thinking but need not delay introductory ML.

## Information Theory and Integrated Practice
- [Dive into Deep Learning](https://d2l.ai/) — entropy, cross-entropy, probabilistic prediction and model training.
- [MML book](https://mml-book.github.io/) — mathematical reference.
- [Stanford CS229](https://cs229.stanford.edu/) — supervised learning and objectives.
- [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) — compare implementations with standard tools.

## Avoid resource overload
1. Pick one primary course per topic.
2. Keep a question list instead of switching resources at every difficulty.
3. Attempt exercises before viewing solutions.
4. Use code to check understanding, not replace derivations.
5. Return to advanced material when a project makes it relevant.
