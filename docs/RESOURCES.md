# Resource Policy — One Primary Spine

## Primary resource (follow completely)

**[Mathematics for Machine Learning — official free book](https://mml-book.github.io/)**

Authors: Marc Peter Deisenroth, A. Aldo Faisal, and Cheng Soon Ong.

This is the one primary resource for the core curriculum. Follow it in order through the ML application chapters. Use the repository's [master curriculum](MASTER_CURRICULUM.md), [mastery protocol](MASTERY_PROTOCOL.md), and [implementation labs](IMPLEMENTATION_LABS.md) to make the reading active.

## Allowed supporting tools

These are not competing courses. Use them only to resolve a specific blocker or verify an implementation.

- [Khan Academy Mathematics](https://www.khanacademy.org/math) — targeted repair of algebra, functions, logarithms, and trigonometry.
- [NumPy Quickstart](https://numpy.org/doc/stable/user/quickstart.html) — array operations and shapes.
- [NumPy linear algebra documentation](https://numpy.org/doc/stable/reference/routines.linalg.html) — verify the behavior of numerical routines after attempting your own implementation.
- [Matplotlib documentation](https://matplotlib.org/stable/) — visualize transformations, distributions, and loss surfaces.
- [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html) — compare your implementation with a standard implementation after you understand the mathematics.

## The no-resource-hopping rule

1. Read the relevant textbook section before searching for another explanation.
2. Write the exact point you do not understand.
3. Try an example and a derivation.
4. If the issue is a prerequisite, repair that one prerequisite using a targeted resource.
5. Return to the textbook and continue.
6. Do not replace the main textbook with a collection of videos or summaries.

## After completing the core

Choose a deeper resource only when you have selected a specialization and can state what the core book did not cover deeply enough. Possible directions include deep learning, Bayesian/probabilistic ML, statistical learning theory, optimization theory, or mathematical research. This is a later decision, not a parallel beginner track.
