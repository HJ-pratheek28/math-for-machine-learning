# Resource Library and Study Method

The canonical resource list is [RESOURCES.md](RESOURCES.md); the complete sequence is [ROADMAP.md](ROADMAP.md). This file exists as a short orientation page for learners who want to understand how to use the repository.

## Non-negotiable workflow

1. Read the assigned section of the primary book, [Mathematics for Machine Learning](https://mml-book.github.io/).
2. Write definitions and dimensions in your own words.
3. Re-derive key results with the source closed.
4. Solve exercises before checking solutions.
5. Implement the mathematical idea in NumPy.
6. Verify with a second method, a finite-difference check, or a known identity.
7. Explain assumptions, limitations and ML relevance.
8. Record evidence in [PROGRESS.md](PROGRESS.md) and use [MASTERY_PROTOCOL.md](MASTERY_PROTOCOL.md) to decide whether to advance.

## Keep resource use disciplined

The primary textbook is the spine. Use prerequisite resources only when a specific gap blocks you. Use advanced books after the corresponding core stage. Do not replace derivation and problem solving with videos or API calls.
