## Recommended setup
```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
python -m pip install numpy matplotlib scipy scikit-learn jupyter
```
On Windows, activate with `.venv\\Scripts\\activate`. Or use [Google Colab](https://colab.research.google.com/) without installing anything.
