# Understand the mathematics behind ML.

Derive the result. Implement the algorithm. Inspect the numerical behavior. Explain what the evidence means.

## The learning loop

**Intuition → derivation → implementation → visualization → verification → mastery.**

This platform is being built in releases. The first slice focuses on a clear curriculum, an original least-squares lesson, and tested Python code. Advanced visualizations, assessment UI, and more research projects will follow the underlying content.

## Seven domains

- Linear algebra and geometry
- Calculus and matrix calculus
- Probability and statistics
- Optimization
- Information theory
- Numerical mathematics
- Advanced mathematical tools for ML
