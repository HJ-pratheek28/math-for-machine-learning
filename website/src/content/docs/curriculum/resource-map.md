# Resource Map

Use one primary source as the spine for each subject. Supplements should solve a specific gap or extend a mastered topic.

- [Harvard Statistics 110](https://projects.iq.harvard.edu/stat110/home)
- [Boyd & Vandenberghe, Convex Optimization](https://web.stanford.edu/~boyd/cvxbook/)
- [MacKay, Information Theory, Inference, and Learning Algorithms](https://www.inference.org.uk/mackay/itila/)
- [Trefethen & Bau, Numerical Linear Algebra](https://people.maths.ox.ac.uk/trefethen/text.html)
- [Murphy, Probabilistic Machine Learning](https://probml.github.io/pml-book/book1.html)

Exact reading assignments should be checked against the linked edition or course.
