# Contributing

Contributions that make this roadmap accurate, useful, and accessible are welcome.

- Correct a broken or outdated resource link.
- Add a high-quality free resource and explain why it helps.
- Improve a topic checklist or exercise.
- Add a small, reproducible Python notebook illustrating a concept.
- Fix typos or clarify an explanation.

## Guidelines
- Prefer official course pages, open textbooks, and educational resources.
- Explain what a resource is best for; avoid link dumps.
- Check exercise calculations before submitting.
- Do not upload copyrighted course material or paid books.
- Keep the repository focused and beginner-friendly.

## Pull request template
- What changed?
- Why is it useful?
- Which links or calculations did you verify?
